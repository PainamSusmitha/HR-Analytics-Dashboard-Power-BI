# HR Analytics Dashboard – Power BI

## 📊 Project Overview
This project analyzes employee workforce data using Power BI to generate HR insights and support better decision-making.

## 🛠 Tools Used
* Power BI
* Excel
* Power Query
* Data Visualization

## 📈 Key Features
* Interactive slicers for Department, Gender, and Employee Number filtering
* KPI cards for Total Employees, Attrition, Attrition %, Avg Age, Avg Salary
* Department and Gender combined analysis
* Age group distribution analysis

## 🔍 Key Insights
* Overall attrition rate is 16.09%
* Research & Development department has highest headcount (930 employees)
* Average employee age is 36.24 years
* Workforce composition: 60.15% male, 39.85% female
* Age group 26-35 has the highest headcount (606 employees)
* Average salary across organization is 6.41K
